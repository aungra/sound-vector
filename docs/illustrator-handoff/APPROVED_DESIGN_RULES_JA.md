# 承認済み32パターンの生成・返却ルール

## 基本方針

今回の `editable/` 32点を、各ジャンルの**承認済みTop1主構造**とする。今後の本番SVGは次の3層で構成する。

1. **Artist master**: Illustrator修正版の線、面、3D構造、削除判断をそのまま使う。
2. **Live audio layer**: 曲の音響指紋から、表示粒子とTop2/Top3ジャンルの構造文法をArtist masterへ融合する。
3. **Protected PCM**: 本番書き出し時だけ、実PCMから可視 `pcm_reversible_data` を生成する。

Illustrator修正版は音の入れ物ではなく主構造の原器である。曲ごとの差は第2層、復元性は第3層が担当する。これにより、手修正した形を固定しながら、異なる曲が同じ完成図になることを防ぐ。

## 共通造形ルール

- `viewBox="0 0 1200 1200"` とジャンルごとの主構造IDを維持する。
- 色は `#000`、`#fff`、`none` のみとし、グレー、透明度、グラデーション、フィルター、ラスタ画像を使わない。
- 承認版と実行時マスターの線幅は `newWidth = sqrt(oldWidth^2 + 4)` で正規化する。0.2pxは2.01px、0.5pxは2.06px、既定1pxは2.24pxとなり、2px未満の可視線を残さない。`editable/` 原本の線幅は変更しない。
- 3D化は「前面または基準線」「奥行き方向の複製」「対応点を結ぶ稜線」の3要素で作る。陰影や半透明で奥行きを表現しない。
- 透視線は主形の読解を補助する本数に留め、閉じた塗り面を無闇に増やさない。開いたワイヤーフレームを優先する。
- Illustratorで削除・縮小された大面積の塗り、壁、円、フレームは復活させない。削除も承認判断の一部として扱う。
- 回転、縦横比、歪みだけを新しい構造とは数えない。主プリミティブ、接続関係、余白の位置が同じなら同一構造である。
- Artist masterへ `terra_grain_field`、`pcm_reversible_data`、`90_PROTECTED_PCM` を混入させない。
- 本番合成の重なり順は、曲固有粒子、Artist master、Top2/Top3構造融合、Protected PCMとする。融合線はArtist masterの実端点・ノードから始め、Protected PCMは静止・無変形で保持する。

## ジャンル比率の融合ルール

- Top1は承認済みArtist masterの主構造を保持する。Top2/Top3の完成図を縮小して周囲へ置かない。
- ジャンル比率は、融合に使う接続サイト数へ変換する。比率が高いジャンルほど接続、置換、反復への参加回数が増える。
- 比率を `scale`、縦横寸法、線幅、透明度へ直接変換しない。Top2/Top3の文法片は固定寸法・不透明で出力する。
- 融合方式は `orthogonal-splice`、`echo-splice`、`pressure-splice`、`fracture-splice`、`counterpoint-splice` からジャンルエンジンに応じて決める。副ジャンルの完成図やアイコンは配置しない。
- Artist master内のpath始点、line端点、circle中心、polygon/rect基準点からノードA/Bを決定的に選び、その間の接続線を副ジャンル文法で組み直す。同じ音響指紋と同じ推定値では同じ接続結果にする。
- Top3以下は小さくするのではなく、接続サイト数を減らしてTop1を上書きしない。各文法片の寸法と線幅は順位にかかわらず維持する。
- SVG rootへ `data-genre-fusion="structural-splice-v2"` と `data-fusion-percentage-policy="site-participation"` を記録する。融合グループには方式、接続数、アンカーポリシーを記録する。
- `pcm_reversible_data` は融合候補、アンカー抽出、変形、表示切替のすべてから除外する。

## 戻し方と自動生成

1. 手修正原本は `editable/` に残し、直接上書きしない。
2. `npm --prefix apps/demo run audit:illustrator-32` で修正前後の比較表を更新する。
3. `npm --prefix apps/demo run build:artist-masters` で `approved/`、承認プレビュー、実行時マスターを再生成する。
4. `npm --prefix apps/demo run preview:genre` で曲固有粒子とProtected PCMを含む実出力32点を生成する。
5. 本番SVGはアプリから書き出し、`pcm_reversible_data` の復号一致を確認する。Artist master単体には音声復元機能を持たせない。

自動生成物は `approved/` と `apps/demo/artist-master-patterns.js` である。次回の手修正は再び `editable/` を入力とし、生成物を編集原本に戻さない。
